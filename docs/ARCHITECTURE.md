# PixelForge architecture (as implemented)

- **App shell**: `src/App.tsx` + `src/router.tsx` (history-API router, no dependency). `vercel.json` rewrites all paths to `index.html`. `/3d` and `/visualizer` are lazy-loaded chunks; a failure there is caught by `ErrorBoundary`.
- **Quality** (`src/quality.ts`): one persisted preference (Performance / Balanced / High) shared by the 2D engine (resolution and particle budget) and the 3D engine.
- **2D engine** (`src/engine.ts`): `Engine` owns one rAF loop, typed arrays for particles, a 64-entry colour palette, and per-preset update/draw code. React only passes validated `Settings` in; it never re-renders per frame. `sanitize()` is the single validation gate for share links, saved artwork and JSON files.
- **State**: React state in `StudioPage`; bounded undo/redo in `src/history.ts` (50 steps, rapid edits coalesce).
- **Persistence** (`src/storage.ts`): LocalStorage (`pixelforge.artworks.v1`), corrupted data is dropped per item; quota errors are surfaced. Autosave is debounced and only touches artworks that already exist.
- **Sharing/export**: `/studio?s=<base64url JSON>` (max 2000 chars, sanitized); PNG via `canvas.toBlob`; settings JSON (versioned, 20 KB limit).
- **Audio** (`src/audio.ts`, `src/pages/VisualizerPage.tsx`): `AudioEngine` wires a file (`<audio>` element) or the microphone into one `AnalyserNode`; `levelsFrom()` turns frequency bins into bass/mid/treble/volume. The page reads its settings from a ref every frame (no React re-render per frame) and draws four modes. `togglePlay()` pauses file playback; `stop()` releases mic tracks, object URL, nodes and context.
- **3D** (`src/graphics/params3d.ts`, `src/graphics/dimension.ts`, `src/pages/Playground3D.tsx`): `params3d.ts` is pure (limits, validation, presets, unit-tested). `DimensionEngine` owns one WebGLRenderer, one rAF loop and one active experience (`Part`): Orbital Sculpture (rings/satellites/core), Particle Nebula (GPU vertex shader, differential rotation, pointer repulsion), Kinetic Geometry (InstancedMesh in grid/spiral/sphere layouts). Quality changes pixel ratio, particle/instance budgets and the bloom pass (`EffectComposer` from three/examples); sustained slow frames lower the quality one level. Pointer position is projected onto a camera-facing plane. `dispose()` frees geometries, materials, composer, listeners and the GL context; a render error or missing WebGL shows a fallback message instead of crashing. Plain Three.js is used (no React Three Fiber). Not yet verified in a real WebGL browser by the author.
- **Cloud** (`src/cloud.ts`, `useUser.ts`, `AccountPage`, `supabase/migrations/`): `@supabase/supabase-js` is loaded by dynamic import only when `VITE_SUPABASE_URL` and `VITE_SUPABASE_PUBLISHABLE_KEY` are set. Authorization lives in Postgres RLS (read own-or-public; insert/update/delete own only; `owner_id` immutable via trigger). Client code treats 0-row updates/deletes as errors, so a failed cloud write is never reported as saved. Stored JSON is re-validated by `sanitize()` on read. Not tested against a real project.
- **Not implemented**: favorites, unlisted links, set-new-password screen, browser tests, PWA.
- **CI**: `.github/workflows/ci.yml` runs `npm ci`, typecheck, test, build (requires a committed `package-lock.json`).
